# PRD：架構說明頁（about-page）

## 目標

面試官問「資料存在哪裡」時直接打開這頁：資料流圖、資料表、保存策略與技術選型。

## 範圍

- **Must**：
  - 路由 `/about`。
  - 資料流圖：inline SVG（深淺主題都清楚），simulator → API → SQLite / web，標出每 10 秒寫入、SSE 每秒、REST 查詢、shared 共用型別。
  - 「資料存在哪裡」：寫入頻率、啟動回填、保留期、分桶查詢、斷線補資料、正式環境替代方案。
  - 四張資料表與欄位、索引說明。
  - 技術選型表與 OpenAPI 文件連結（`/api/docs`）。
  - 依目前模式顯示資料位置（API：後端 SQLite；mock：瀏覽器記憶體）。
- **Won't**：互動式架構圖。

## 驗收標準

- [x] AC-01：圖有 `<title>` / `<desc>`，螢幕閱讀器可讀。
- [x] AC-02：400px 寬不出現水平捲軸（表格區塊內可橫向捲動）。
