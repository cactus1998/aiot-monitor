# PRD：總覽頁（overview-page）

## 目標

廠長打開首頁就看到所有機台狀態與今日 OEE。對應總規格 AC-01。

## 範圍

- **Must**：
  - 路由 `/`（hash 路由 `#/`）。
  - KPI 卡片：運轉率、OEE（儀表圖，含可用率 / 效能 / 良率）、今日產量（含良率）、未處理告警（連到告警中心）。
  - 機台狀態圓餅圖：即時（來自 live store），中心顯示機台總數。
  - 班別產量長條圖（大夜 / 早 / 中班）。
  - 機台卡片：名稱、狀態（顏色 + 圖示 + 文字）、溫度、振動、主軸負載、轉速、今日產量；點擊進詳情頁；每秒更新。
  - 總覽數字每 10 秒重新取 `/api/stats/overview`。
- **Won't**：自訂 KPI、拖拉排版。

## 驗收標準

- [x] AC-01：Given API 啟動，When 開啟總覽頁，Then 3 秒內看到 8 台機台、KPI 與圓餅圖，且每秒更新。
- [x] AC-02：API 錯誤時 KPI 區塊顯示錯誤與重試，機台卡片不受影響（總規格 EC-03）。
- [x] AC-03：400px 寬時 KPI 兩欄、圖表全寬。
