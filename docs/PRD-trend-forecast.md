# PRD：趨勢預測（trend-forecast）

## 目標

用最簡單、可解釋的方法示範「預測性維護」：對最近一段資料做線性迴歸，估算多久會碰到告警閾值。

## 範圍

- **Must**：
  - shared `linearRegression(points)`：最小平方法，x 先減去第一點時間避免精度問題，回傳斜率、截距、R²。
  - shared `forecastThreshold(points, threshold)`：已超過回 `reached`；斜率 ≤ 0 回 `eta: null`；否則回到達時間。
  - 機台詳情頁：溫度、振動、主軸負載三張圖取最近 15 分鐘（至少 10 點）計算，圖上畫紫色虛線趨勢線，圖下顯示：
    - 已達閾值：「建議立即檢查」（紅）
    - 30 分鐘內：紅；2 小時內：橘，顯示預計時間與「建議安排保養」
    - 超過 2 小時或趨勢持平：灰
    - 附 R²，讓使用者判斷可信度。
- **Won't**：季節性模型、機器學習、轉速預測（轉速沒有上限型告警的意義）。

## 驗收標準

- [x] AC-01：完美直線測資的斜率與到達時間正確；少於 2 點回 null；下降趨勢不預測。
- [x] AC-02：注入 `overheat` 異常後，溫度圖出現預計到達時間。

## 開發紀錄
