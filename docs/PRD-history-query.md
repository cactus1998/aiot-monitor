# PRD：歷史查詢（history-query）

## 目標

核心查詢流程：「選條件 → 打 API → 同一批資料同時呈現為表格與折線圖」，加上匯出 CSV。

## 範圍

- **Must**：
  - 路由 `/history`，篩選條件同步到 URL query：`machineId`、`metric`、`from`、`to`、`page`、`pageSize`、`sort`；非法值回到預設（CNC-01、溫度、最近 1 小時、第 1 頁、50 筆、`-ts`）。
  - 篩選表單：機台（含「全部機台」）、指標、開始 / 結束時間（台北時間 `datetime-local`）、快捷範圍（1h / 6h / 24h）。
  - 前端驗證：開始 ≥ 結束或超過 24 小時時阻擋送出並顯示訊息（總規格 EC-08）。
  - 表格：`/api/readings` 伺服器端分頁排序。
  - 折線圖：選定機台時打 `/series`；「全部機台」時每台一條序列（8 個請求並行）。
  - 連動：點表格列，折線圖在該時間顯示垂直標記並顯示 tooltip；圖表 dataZoom 範圍顯示在圖下方。
  - 匯出 CSV：與表格相同條件（不含分頁），下載檔名含機台與時間；匯出中按鈕 disabled。
  - 競態：條件快速變動時 abort 前一個請求（總規格 EC-01）。
- **Won't**：多指標同時查詢、儲存查詢條件。

## 驗收標準

- [x] AC-01：選擇機台與時間範圍送出，表格與折線圖顯示同一批資料，表格可排序與分頁（總規格 AC-03）。
- [x] AC-02：匯出的 CSV 筆數等於表格總筆數（總規格 AC-04）。
- [x] AC-03：重新整理頁面後條件與結果還原。
- [x] AC-04：composable 測試涵蓋 success、empty、error、競態。
