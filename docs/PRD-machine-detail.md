# PRD：機台詳情頁（machine-detail）

## 目標

設備工程師在單一機台頁看到多指標即時曲線與閾值，及早發現異常。對應總規格 AC-02。

## 範圍

- **Must**：
  - 路由 `/machines/:id`，範圍 `?range=1h|6h|24h`（URL 同步，非法值回到 `1h`）。
  - 四張折線圖（溫度、振動、主軸負載、轉速），2×2 排列（手機單欄），各自有警告與告警閾值線。
  - 資料：`/series`，`points=720`（繪製點數 ≤ 2000）；四張圖以 ECharts `connect` 連動 tooltip 與 dataZoom。
  - 1h 範圍：每秒從 live store 追加即時點，視窗往前滑動；6h / 24h 每 60 秒重新取資料。
  - 機台資訊列：狀態、型號、產線、理想週期、今日產量。
  - 事件列表：此機台最近 20 筆告警（`/api/alerts?machineId=`），即時收到新告警時插入。
  - 不存在的機台 id：顯示「找不到機台」與返回總覽連結。
- **Won't**：指標自訂、比較兩台機台。

## 驗收標準

- [x] AC-01：切換 1h / 6h / 24h，折線圖點數 ≤ 2000 並顯示閾值線（總規格 AC-02）。
- [x] AC-02：1h 範圍每秒追加新點，不重建 ECharts instance。
- [x] AC-03：離開頁面後計時器清除、圖表 dispose（總規格 EC-10）。
